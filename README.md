# M&M Studio

Сайт студии Миши Гантимурова и Миши Останина: девять кейсов, полный шоурил, анимационная заставка, фотографии и контакты.

## Запуск

Нужен Node.js 22.22 или более новая совместимая LTS-версия.

```sh
npm ci
npm run dev
npm run build
```

Готовый статический сайт находится в `dist/client`. Содержимое этой папки можно разместить на обычном статическом хостинге. Серверная база данных и секретные ключи не нужны.

## Где редактировать

- `app/page.tsx` — тексты, кейсы, контакты, воспроизведение видео.
- `app/globals.css` — оформление, адаптивность, анимация лампы и круглые портреты.
- `app/layout.tsx` — название и описание сайта.
- `public/media/full` — полные оптимизированные ролики.
- `public/media/previews` — короткие видео и обложки.
- `public/images` — фотографии и персонажи.

Видео, изображения и шрифтовый стек не зависят от внешних CDN. Telegram и страницы публикаций — дополнительные ссылки; ролики воспроизводятся локально на сайте. Полные видео загружаются при открытии кейса. Звука без действия посетителя нет. Учитывается системное предпочтение уменьшения движения.

## Публикация и доступность

`.openai/hosting.json` связывает исходники с приватным предпросмотром Sites. Для публичного запуска в России подойдёт отдельный статический хостинг с проверенным доступом из российских сетей. После выбора домена нужно обновить `metadataBase` в `app/layout.tsx`. Доступность без VPN из разных сетей ещё не проверена и не гарантируется.

Автомобильные работы подписаны как концепты. Публикация клипа НАК не обозначает заказ от НАК. Референсы с дверью и магазинными продуктами не включены, поскольку их авторство не уточнено. Исходные отметки Veo сохранены. Фотографии, видео и контакты предоставлены владельцем проекта.

Заставка использует векторную шарнирную лампу с анимацией прыжков по буквам. Фотографии команды оформлены круглыми портретами через CSS. Шоурил включает самостоятельно созданную инструментальную подложку; это первая монтажная версия.
